# Wish Card

> WishCard is a production-ready PHP festival greeting platform to create, personalize, and share beautiful wish posters for Diwali, Holi, Eid, New Year, and Raksha Bandhan. It includes secure uploads, CSRF/session hardening, admin dashboard with search/pagination, share links, downloadable cards, and dynamic SEO sitemap support on modern web hosting


---

## ✨ Features

- Modern developer experience
- Automated CI/CD workflows
- Robust security hygiene
